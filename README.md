# 🚀 Java Masterclass — De Zéro à Junior Backend Developer

> Parcours complet d'apprentissage de **Java 21** puis **Spring Boot**,
> avec pour objectif de devenir **Junior Backend Developer**.
>
> Chaque leçon est indépendante, documentée, avec des exercices, des QCM,
> des challenges et des projets professionnels.

---

## 🎯 Objectif final

À la fin de ce parcours, je serai capable de :

- ✅ Lire et écrire du code Java propre.
- ✅ Maîtriser la Programmation Orientée Objet (POO).
- ✅ Utiliser les collections, Streams, Lambda, Optional, Date/Time.
- ✅ Gérer les exceptions proprement.
- ✅ Construire une API REST avec Spring Boot.
- ✅ Connecter Spring Boot à MySQL avec JPA/Hibernate.
- ✅ Utiliser des DTO et Mappers pour sécuriser l'API.
- ✅ Valider les données avec Bean Validation.
- ✅ Gérer les exceptions globalement (`@ControllerAdvice`).
- ✅ Implémenter Spring Security + JWT.
- ✅ Écrire des tests (JUnit, Mockito).
- ✅ Documenter une API avec Swagger/OpenAPI.
- ✅ Dockeriser une application.
- ✅ Déployer une application.
- ✅ Présenter mes projets sur GitHub et LinkedIn.
- ✅ Répondre aux questions techniques d'un entretien Junior Java Backend.
