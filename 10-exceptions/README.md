
# 🚀 Leçon 10 — Les exceptions

## 📖 Ce que j'ai appris dans cette leçon

J'ai appris à gérer les erreurs et les situations inattendues dans mon code. Les exceptions permettent d'éviter que le programme plante brutalement et d'informer l'utilisateur de façon claire.

## 🔑 Les concepts fondamentaux

### 1. Qu'est-ce qu'une exception ?

Une **exception** est un événement qui perturbe le flux normal d'exécution d'un programme.
